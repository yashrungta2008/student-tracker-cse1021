Student Attendance and Performance Tracker

This is a simple terminal-based program. It helps teachers manage student profiles, calculate exam averages, and check attendance rules without needing a complex interface.

Project Features
* Clean code split into different files for input checks, grades, and records.
* Custom selection sort algorithm to rank students by their marks.
* Automated warnings for students whose attendance drops below 75%.

Prerequisites
* You only need Python 3 installed on your computer.

How to Install and Run
1. Download all the project files into a single folder named `student_tracker`.
2. Open your terminal or command prompt.
3. Move into the project folder:
   ```bash
   cd student_tracker
   ```
4. Run the program using this command:
   ```bash
   python main.py
   ```

Testing the Program
* Open the menu and choose option 1 to add a student. Try entering letters instead of numbers for grades to see how the program stops invalid entries.
* Add 3 different students with different marks, then select option 4 to see if the custom sorting works correctly.
