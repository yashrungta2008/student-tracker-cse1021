Project Plan: Student Tracking System

What is the Problem?
Teachers often find it hard to keep track of student grades and attendance when using regular spreadsheets. It takes too much time to figure out who is failing or who is skipping too many classes.

Scope of the Project
This project is a simple command-line program to manage student data. It allows users to add or delete students, sort students by their test averages using a custom sorting algorithm, and quickly check who has less than 75% attendance. All data is saved inside the program's memory while it runs.

Target Users
* Class teachers who need to check daily student performance.
* Course coordinators who want to see who the top students are.

Main Features
* **Student Registry:** Add, view, and delete student profiles.
* **Grade Analyzer:** Calculate student averages and sort them from highest to lowest.
* **Attendance Alerts:** Instantly find and list students with low attendance.
